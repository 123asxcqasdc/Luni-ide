==================================================
  Luni IDE — как установить и запустить (для ученика)
==================================================

1. УСТАНОВКА

   Windows:
      Запусти установщик  Luni-IDE-Setup-x.x.x.exe  и пройди установку
      (права администратора НЕ нужны — программа ставится в твою папку
      пользователя). На последнем шаге будет две галочки:
         [ ] Установить драйвер CH340  — поставь её, если плату ESP32
             раньше на этом компьютере не подключали;
         [v] Запустить Luni IDE.
      Драйвер нужен, чтобы компьютер «увидел» плату. Он ставится сам,
      одной командой — появится только окно с вопросом про права
      администратора: нажми «Да». Ничего больше нажимать не нужно.

   Debian / Ubuntu / Mint:
      В терминале:
         sudo apt install ./luni-ide_x.x.x_amd64.deb
      Драйвер ставить не нужно — CH340 уже есть в Linux. Но один раз надо
      разрешить доступ к порту:
         sudo usermod -aG dialout "$USER"
      и перелогиниться (или перезагрузить компьютер).
      Запуск: меню приложений → «Luni IDE» или команда  luni-ide

   AppImage (любой Linux, без установки):
         chmod +x Luni-IDE-x.x.x-x86_64.AppImage
         ./Luni-IDE-x.x.x-x86_64.AppImage
      И не забудь про группу dialout (см. выше).

2. ПОДКЛЮЧИ ПЛАТУ ESP32 К USB.

3. ЗАПУСТИ Luni IDE (ярлык на рабочем столе, в меню или из терминала).
   Откроется окно среды программирования (или вкладка браузера).

4. В правом верхнем углу нажми кнопку «обновить порты» (значок ↻)
   и выбери порт платы:  COM3 (Windows) или /dev/ttyUSB0 (Linux).

5. Пиши код. Кнопки:
   - «Проверить»  — только компиляция            (Ctrl+R)
   - «Загрузить»  — прошить программу на плату    (Ctrl+Enter)
   Смотреть, что плата шлёт в Serial, — вкладка «Serial»
   справа, кнопка «Подключить».

   Проект сохраняется сам. Меню «Файл»:
   - Новый проект        (Ctrl+N)
   - Открыть проект…     (Ctrl+O)
   - Примеры             — готовые примеры из библиотек
                           (открываются копией — портить не страшно)
   - Сохранить как…      (Ctrl+S)
   - Последние проекты   — список недавних.

   Поиск по коду — Ctrl+F, поиск с заменой — Ctrl+H.

--------------------------------------------------
ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
--------------------------------------------------
- Порт не появляется       -> Windows: не поставлен драйвер CH340 (шаг 1)
                              или плохой/зарядный кабель без данных.
                              Linux: нет прав на порт — проверь группу
                              dialout (шаг 1) и перелогинься.
- При прошивке «Connecting…» -> удерживай кнопку BOOT на плате,
                              когда началась прошивка.
- Первая компиляция долгая  -> это нормально, дальше будет быстрее.
- «arduino-cli не найден»   -> Linux: один раз выполни
                                  python3 /opt/luni-ide/setup_toolchain_linux.py
                               (скачает компилятор и ядро ESP32).

Интернет НЕ нужен — всё работает офлайн.
